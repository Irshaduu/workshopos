# 0004: SaaS business features wait for a second workshop

**Status:** Accepted (2026-10-08)

## Context

Selling to other workshops is possible but not certain. SaaS business features
take time to build and add code to maintain.

## Decision

- **Build now (the tenant foundation):** a workshop link on every business
  record, memberships, per-workshop settings and number series.
- **Build only when a second workshop wants the system:** self sign-up,
  subscription billing, a platform admin console, per-workshop feature
  switches, pricing plans.

## Consequences

- If the system is never sold, little was wasted.
- If it is sold, the foundation is ready and only the business features remain.
